🏥 Executive Healthcare Performance Dashboard

📌 Project Overview

An executive-level Power BI dashboard designed to provide Directors and decision-makers with a clear and comprehensive overview of healthcare business performance.

The dashboard enables users to monitor key financial and operational KPIs, compare actual performance against targets and historical results, and analyze performance across different departments and business units.

⸻

🎯 Dashboard Objectives

The main objective of this dashboard is to transform complex healthcare data into clear, actionable insights for executive decision-making.

It focuses on tracking and comparing:

* Total Revenue
* OPD Volume
* Total CPV
* Baseline
* Actual
* Historical Performance
* Target
* Achievement %
* Growth %

⸻

📊 Dashboard Features

💰 Executive KPI Performance

Monitor major healthcare KPIs and evaluate performance against:

* Baseline
* Actual
* Historical
* Target
* Achievement %
* Growth %

🔎 Interactive Filters

The dashboard provides interactive filtering options for:

* Country
* Business Unit

* Payment Type

This allows users to explore performance dynamically based on different business dimensions.

🏥 Department-Level Analysis

Analyze healthcare performance across different departments, including:

* ICU
* NICU

* And other healthcare departments

🏢 Business Unit Performance

Compare performance across different business units, including:

* Digital Marketing
